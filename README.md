# 图片与移动水印修复工具

上传源码、版本发布与后续维护见 [GitHub 操作指南](GITHUB_GUIDE.md)。

Windows 本地工具。打开后先选择“图片 · 单张 / 批量去水印”或“视频 · 移动水印处理”。
图片在第一张上框选一次，在整套图片中自动匹配相似水印；
视频使用边缘模板逐帧匹配移动水印，再修复矩形区域。
不上传文件。原文件保留，视频输出为 H.264 MP4，并将原音轨转为 AAC。

## 安装与启动

使用打包好的 `WatermarkCleaner.exe`，不需要安装 Python。
GitHub 使用者可从本仓库 Releases 下载发布附件（维护者发布后可用）。
当前本机已验证的程序位于 `dist_v3/WatermarkCleaner.exe`。
打包结果不会随源码仓库上传。
下面仅为源码运行方式。

安装 Python 3.10 或更新版本（包含 Tkinter），在此目录打开终端：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe cleaner.py
```

## 使用

### 图片批量处理

1. 打开程序，选择“图片 · 单张 / 批量去水印”。
2. 多选一套图片，也支持只选一张。程序会显示第一张的文件名作为参考。
3. 紧贴参考水印框选，按 Enter 确认。
4. 选择输出位置。程序自动新建 `cleaned_` 开头的子文件夹，不覆盖原文件。
5. 查看进度，可取消剩余任务。已完成结果保留，原图始终保留。
6. 修复结果输出为 PNG；未匹配的原图副本放在结果目录的“未匹配”子文件夹，
   保留原文件名，同名时自动追加数字。原始位置的文件保留。
   `batch_report.json` 记录成功、未匹配、失败及未处理数量和图片保存路径。

匹配会搜索整张图片，并尝试多个水印大小及图片分辨率比例。
适合相同或相似 Logo、文字水印；内容差别大、背景干扰或半透明时可能匹配失败。
低于匹配阈值的图片不修复，复制到“未匹配”文件夹；高分匹配也可能出错，请检查结果。
暂不支持一张图中自动消除多个水印。可分批选择更相似的参考图再次处理未匹配图片。

### 视频处理

1. 打开程序，选择“视频 · 移动水印处理”，再选择视频。
2. 视频第一帧必须能看到水印。紧贴文字或 Logo 框选，少包含背景。
3. Enter 确认选区。视频选择处理方式：自动跟踪适合固定外观；
   关键位置模式适合外观变化，输入时间并框选各帧水印。
   位置和选区大小在关键帧之间线性插值，最后一个位置之后保持不动。
   水印跳动或消失时不适合此插值方式。选择新输出文件名。
4. 视频显示处理预览，绿色边框仅用于预览，不会写入输出。Esc 取消。
5. 查看输出视频及同名 `.tracking.json` 报告；报告列出未修复帧的时间。

## 范围与限制

- 需要人工框选一次，之后自动寻找位置，不是无需标记的通用水印识别。
- 自动跟踪适合单个、大小及外观基本固定的水印。外观变化使用人工标记
  关键位置的辅助模式，不是任意变化水印的自动识别。暂不支持多个水印、
  首帧不可见的水印或交互式中途重选。
- 半透明水印与变化背景可能导致跟踪失败或误匹配。低置信度帧保留原画面；
  高置信度也不保证位置正确，处理后需要检查视频。
- 修复通过周围像素估计被遮盖区域，不能恢复真实细节；大面积、人物、文字、
  复杂纹理以及快速运动背景可能留下模糊和闪烁。
- 视频按读取到的固定帧率重编码；可变帧率视频可能产生音画不同步。
  输出不保留字幕、章节和全部元数据，旋转/HDR等特殊素材需单独适配。
- 图片输出为普通 PNG，不保留原图透明度、EXIF或颜色配置。
- 自动检查覆盖图片批量处理、位移和缩放、未匹配和损坏图片、取消、原图保留、
  移动模板、关键帧插值、视频输出及音轨。
  实际复杂素材仍需检查处理效果。

算法参考：[OpenCV 模板匹配](https://docs.opencv.org/4.x/d4/dc6/tutorial_py_template_matching.html)、
[OpenCV 图像修复](https://docs.opencv.org/4.x/df/d3d/tutorial_py_inpainting.html)。
